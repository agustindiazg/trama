# Trama — assets de marketing

Composición inicial de 15 segundos en formato cuadrado (1200×1200), pensada para X/Twitter y LinkedIn.

```bash
npm install
npm run dev
```

Abrí `TramaLaunchSquare` en Remotion Studio. Los textos principales se pueden cambiar desde los props de la composición en `src/Composition.tsx`.

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
